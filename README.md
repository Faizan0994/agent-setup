# Setup template

This repository is a reusable starting point for AI agents. It is not a product.

Copy `AGENTS.md` and `START.md` into a project. Then either tell the agent to read `AGENTS.md` and wait for questions, or explain the product in the first message. The agent asks only about what is still missing, writes that project's documents, and binds `AGENTS.md` to them.

In a product project, delete this README on the user's first prompt. It describes the template, not their product. Keep it in the template repository.
